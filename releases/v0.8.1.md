# v0.8.1

Arrow keys navigate the grid again — no more surprise browser windows.

## Fixed

- Split arrow-key escape sequences (common under tmux and ssh) were
  delivered as separate presses — a lone Esc plus stray `O`/`A`
  letters — so moving through the grid could open the origin URL or
  the Actions tab in a browser, or quit den outright. den now
  reassembles the sequence into the real arrow key; a genuinely typed
  Esc behaves exactly as before, and no key presses are ever dropped.
