# v0.5.0

_Multiple bases, faster triage actions, and Den finally tells you when something changes underfoot._

## Highlights

- **Multiple base directories.** `den ~/work ~/personal` watches both folders in one grid. Header shows the first base with `+N more` so it stays compact.
- **Sort: CI red first** (`O`). Toggles a leading "ci red" section that surfaces failing CI repos regardless of their normal dirty/clean grouping. Useful when "what's broken?" is the question of the moment.
- **Quick pull** (`P`). Runs `git pull --ff-only` on the focused repo with the same spinner / refresh flow as `F`. Stays safe: no merge or rebase, just fast-forward.
- **Stash overlay** (`S`). Lists stash entries with selector, relative time, and message — answering "what did I leave behind?" without reaching for `git stash list`. Mutually exclusive with the README overlay (`i`).
- **Open-PR badge.** Each tile gets a `PR<N>` badge when you have open PRs you authored on that repo (via `gh pr list --author @me --state open`). Sits next to the CI dot in the tile title.
- **State-change flash.** When a watched repo flips clean ↔ dirty or gains conflicts (e.g., you changed branches in another terminal), the footer announces it. File-watcher and fetch updates trigger this; bulk `r` refresh stays quiet to avoid noise.
