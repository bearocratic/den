# v0.9.0

den now sits in the macOS menu bar as well as in a terminal.

## Highlights

- A menu bar app: one glyph that says whether anything needs you, and
  a menu listing every watched folder and the repositories inside it.
  It reads and opens — nothing in it writes to a repository.
- The watcher moved into a `den-core` crate, so the menu and the TUI
  describe the same repositories the same way, in the same palette.

## New

- **den in the menu bar.** The glyph carries one state, the worst one:
  CI failing, else something dirty or unpushed, else clean. The menu
  shows each folder with its roll-up — repos, dirty, CI failing — and
  each repository with branch, ahead/behind, staged, modified,
  untracked, conflicts, stash, latest tag and CI.
- A row opens a shell where the repository is. Command opens it on
  GitHub, option in the editor, shift in the Finder; a row whose CI is
  red opens the failing run.
- Folders can be added and dropped from the menu. They live in
  `~/.den/bar.toml`, seeded once from the folders den has already seen
  and pruned of nesting, so watching a folder and a folder inside it
  never lists everything twice.
- Pins come from the session for that exact set of folders, and hiding
  is den's global list, so both surfaces agree about what to show.

## Changed

- Repository scanning, the session store, the GitHub lookups, the
  ordering rule and the palette now live in `den-core`. The TUI is
  unchanged in behaviour; it is simply no longer the only surface.
- The menu fetches far less often than the TUI — fifteen minutes by
  default — because it runs all day. CI is rendered from the last
  answer with its age rather than blocking on the network.

## Install

The CLI, as always:

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```

The menu bar app is a signed, notarised disk image:

```sh
open https://bearocratic.dev/download/den/den-macos-universal.dmg
```
