# v0.9.5

A folder you open in a terminal is a folder the menu bar watches.

## New

- **`den <folder>` adds what it was pointed at** to the folders the
  menu bar app watches, and says so. The two surfaces now share one
  list instead of each keeping its own.
- **The app follows that list while it runs.** Change it — from a
  terminal, from the app, or by hand — and it re-watches and rescans
  at once, without a restart.

## Fixed

- **Add folder… did nothing.** Keeping the app out of the Dock also
  keeps it from ever becoming the active application, so the folder
  chooser opened behind everything or not at all. It becomes an
  ordinary app for exactly as long as the chooser is up.
- **A build from source crashed on launch.** The updater plugin
  refuses to start without a configuration saying where updates come
  from, which this repository deliberately does not carry. The plugin
  is now loaded only when such a configuration exists; a build without
  one shows its version and does not offer a check it cannot make.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
