# v0.2.0

_Grid gets some structure: tiles group by status, the preview is always on._

## Highlights

- Repo tiles are now organised under labeled section bands — **conflicts**, **dirty**, **clean**, **hidden** — coloured to match each state. The repos that need attention are always at the top of the grid instead of mixed in.
- Detail preview opens by default. The grid sits on the left, status / diff / history / releases on the right. `Enter` still toggles the preview off when you want a full-width grid.

## Changed

- Grid column count is capped at 4. On wide terminals tiles get wider rather than wrapping into a ragged trailing row.
- Tiles inside a section keep the existing pinned-first ordering, so starred repos stay surfaced at the top of their band.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
