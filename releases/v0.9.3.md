# v0.9.3

You can ask den whether it is up to date.

## New

- **Check for updates…**, in the menu and in the tray menu beside it.
  One item carries the whole story: `Check for updates…`, then
  `Checking…`, then either `den is up to date` or `Update to vX.Y.Z`,
  which installs it.

## Changed

- The automatic check is unchanged and stays quiet — at startup and
  every six hours, saying nothing unless there is something to
  install. Only an answer someone asked for is worth showing when the
  answer is "no".

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
