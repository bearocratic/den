# v0.9.1

The app in the menu bar is named den.

## Fixed

- The bundle was `den.app` with `den-bar` inside it — the crate is
  `den-bar`, because the workspace already has a package called `den`
  and two binaries of one name collide in a single target directory.
  The executable is now renamed as the bundle is made, so the app, the
  executable and Activity Monitor all say den.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
