# v0.9.4

Quit quits, and the menu says which den you are running.

## Fixed

- **Quit did nothing**, in either menu. Both paths asked the app to
  exit, which raises the same event the app refuses so that closing
  the menu does not end it — so the refusal swallowed the asking too.
  Quitting now goes around it, after the app has tidied up.

## Changed

- The update item carries the running version:
  `den 0.9.4 · check for updates…`, and `den 0.9.4 · up to date` once
  it has asked. It could offer you the next version while saying
  nothing about the one you had.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
