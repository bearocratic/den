# v0.3.0

_Den fetches in the background, the right pane gets out of the way, and the palette finally reads on dark terminals._

## Highlights

- **Background fetch.** Den now runs `git fetch --quiet --no-write-fetch-head --all` for every discovered repo on a timer (default every 5 minutes). Ahead/behind badges on each tile update as the remote advances, no manual refresh needed. The header shows `↻ syncing…` while a cycle runs and `last sync: 2 min ago` between cycles.
- **Drop into a shell at the focused repo.** Press `s` to suspend Den and spawn `$SHELL` inside the selected repo. Exit the shell and Den resumes, refreshes status, and you're back where you were. Joins `e` (editor), `o` (lazygit), and `g` (open on GitHub) as one-key actions.
- **Right pane: status + diff only.** History and Releases are gone as panel sections — they were crowding the view without earning the space. The detail pane is now `status` (compact) and `diff` (the rest), with a richer title bar showing `name · branch · ↑↓ · last release: 2d ago`. Focus keys collapse from `1/2/3/4` to `1/2`.
- **Dark-terminal palette.** Brand colors are now derived from chancery's dark-mode pattern: muted text uses ivory blended at 64%/46% opacity instead of the deep stones, and forest is brightened so "clean" actually shows up.

## Changed

- New CLI flag: `--fetch-interval <seconds>` (default `300`). Pass `--fetch-interval 0` to disable background fetching entirely.
- Auth-prompting fetches don't hang the cycle: `GIT_TERMINAL_PROMPT=0` is set on background fetches so SSH/HTTPS prompts return immediately instead of blocking.
- Diff view drops the `--stat` summary; just the patch.
- Header bar shifts to amber tones; sync indicator lives on its own line so it doesn't overflow.
