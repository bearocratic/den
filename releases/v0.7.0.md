# v0.7.0

_Sessions are readable now: a folder named `bearocratic` instead of `74541c3e638a716f`._

## Highlights

- **Slug-based session ids.** Session directories are now named after the basenames of the bases you opened with — `~/Projects/bearocratic` becomes `bearocratic`, `~/work ~/personal` becomes `work-personal`. If two unrelated path sets ever slug to the same name, the second gets a short hash suffix (`bearocratic-3e8a`). Existing 16-hex sessions are renamed to slugs on first launch.
- **`den open <id>`.** Reopen a saved session by its id; Den reads the session's `bases.txt` and launches the TUI with those folders. No need to retype paths.
- **Settings now use TOML.** `settings.kv` becomes `settings.toml` (one per session). The schema is the same — `sort_ci_first`, `show_hidden`, `last_filter` — but evolves more cleanly the next time we add nested config. Existing `settings.kv` files are auto-converted on load and removed.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```

Or via cargo:

```sh
cargo install --git https://github.com/bearocratic/den --tag v0.7.0
```
