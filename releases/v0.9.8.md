# v0.9.8

A new mark in the menu bar.

## Changed

- **The glyph is a `d`** — the `b` from the bearo wordmark, mirrored —
  in place of the arch. Monochrome, as a menu bar icon should be: it
  is dimmed when nothing needs doing, full when something is dirty or
  unpushed, and red when CI is failing.

## Note

No code changed between v0.9.7 and this release. The mark ships with
the signed app rather than from this repository, which carries a
neutral one, so the version moves to tell the two builds apart.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
