# v0.8.0

_More glance, more act: cycle sorts, narrow to one base, see all your PRs in one screen._

## Highlights

- **`L` opens an open-PRs overlay.** Lists every open PR you authored across the watched repos in one screen — `#NUM  <repo>  <title>  <date>` plus the underlined URL. Sorted by repo. Backed by a richer `gh pr list` query that captures titles and URLs, not just counts.
- **`O` cycles four sort modes.** Default → CI red first → dirty first → by recency → default. Persisted per session, so each project remembers how you scan it.
- **`b` filters to one base.** When watching multiple folders (`den ~/work ~/personal`), `b` cycles: all → base 1 → base 2 → all. Header announces the active filter via flash.
- **`Y` copies the GitHub URL.** Paired with lowercase `y` (path). Same key, capital = remote.
- **CI completion flash.** When a CI run on a watched repo flips from running to success or failure, the footer announces "CI passed/failed on `<repo>`". Only on the transition — no flood on initial discovery.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```

Or via cargo:

```sh
cargo install --git https://github.com/bearocratic/den --tag v0.8.0
```
