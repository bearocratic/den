# v0.4.0

_Filter, manual fetch, and CI status — Den answers a new triage question: "is anything red?"_

## Highlights

- **CI status badge per tile.** Each tile now shows a coloured dot — `●` green for pass, `●` red for fail, `◐` amber while a run is in progress, `○` dim for unknown. Sourced from `gh run list --commit <HEAD>`, so it tracks the actual commit you're sitting on (not random older runs on the branch).
- **Failure detail in the status pane.** When CI is red on the focused repo, the status section leads with a one-liner: `● CI failed: <workflow> · <job → step>  <run-url>`. Backed by a second `gh run view` call that surfaces the first failed step name, so you know *what* broke without leaving the TUI. Press `A` to jump straight to the workflow run in your browser.
- **`/` filter.** Type `/` then a query to narrow the grid by repo name. `Esc` clears, `Enter` confirms. The filter input shows on the second header row with a blinking caret.
- **`F` to fetch the focused repo right now.** Complements the 5-minute background cycle when you want freshness immediately. Tile shows a braille spinner while the fetch runs.
- **`A` to open the GitHub Actions tab** for the focused repo, scoped to the current branch when known.
- **Interactive startup.** Den now narrates what it's doing as it boots: animated spinner during scan, per-repo progress counter while reading status, and a `✓` / `⚠` / `✗` line for each step. Auth check tells you if `gh` isn't logged in instead of just leaving badges blank.
- **Initial CI prime.** Badges populate within seconds of launch — no need to press `F` or wait for the first 5-min fetch cycle.

## Changed

- New CLI flag `--no-ci` to disable all `gh run list` / `gh run view` calls (silences the auth-check warning too).
- Per-tile spinner: any in-flight fetch (background, manual `F`, or initial CI prime) shows a braille spinner glyph in the tile title until the work completes.
