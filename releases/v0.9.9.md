# v0.9.9

A check that cannot be made no longer reports good news.

## Fixed

- **"Up to date" was said when the check had failed.** Every error —
  no network, a signature that would not verify, a manifest that would
  not parse — was turned into "no update", which the menu showed as
  "up to date". The two are now told apart: a failed check reads
  `could not check`, in red, with the reason behind it, and the log
  says what went wrong.

## Changed

- **The highlight is den's own accent.** It was the system accent,
  which is whatever colour you have set — blue, for most people. The
  menu now uses forest on a light bar and the sheet purple on a dark
  one, like the rest of the bearo world.
- **The app icon is the `d`**, the same mark as the one in the menu
  bar, in place of the arch.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
