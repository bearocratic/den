# v0.1.0

_First cut of Den — a terminal watcher for the git repositories in a folder._

## Highlights

- Tile grid per repo with branch, ahead / behind, latest tag, last-commit summary, and dirty counts (staged / modified / untracked / conflicts / stash) at a glance.
- Detail pane stacks **status**, **diff**, **history**, and **releases** side-by-side — no tab-switching. Each section scrolls independently.
- README overlay with a proper markdown renderer (`pulldown-cmark`); `m` toggles between rendered and raw source.
- Command palette (`:`) — every action, every shortcut, in one filterable list.
- Pin (`p`) and hide (`x`) repos. Both persist to `~/.config/den/`.
- Quick actions: open in `$EDITOR` (`e`), drop into lazygit (`o`), open the repo's GitHub origin (`g`), copy path (`y`).
- Live filesystem watcher debounces tile updates; 30-second safety refresh catches anything missed.
- Bearocratic brand palette throughout — forest / amber / amber-strong / stone / ivory.

## Install

```sh
brew tap bearocratic/tap
brew install den
```

## Usage

```sh
den                   # scan the current directory
den ~/Projects        # scan a specific folder
den --depth 6 .       # change recursion depth (default 4)
```

Press `:` for the full command list.
