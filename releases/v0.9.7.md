# v0.9.7

"Up to date" stops being true after a while.

## Fixed

- **The answer about updates was stamped once and never expired.** Ask
  while a release is still going out — the terminal build publishes
  about ten minutes before the signed app joins it — and the menu
  would go on saying you were current long after you were not. The
  answer now carries when it was given, and is only shown while it is
  under a minute old; after that the item offers a check again rather
  than claiming a result.

## Changed

- **Opening the menu asks again** when the last answer is older than
  half an hour. The six-hour check stays silent, but the moment
  someone is looking is a fair moment to find out.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
