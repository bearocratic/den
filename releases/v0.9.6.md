# v0.9.6

The menu bar icon behaves like a menu bar icon.

## Changed

- **Monochrome, the way the rest of the bar is.** Clean and dirty are
  template images now: black with alpha, which macOS inverts for a
  light bar, paints white on a dark one, and dims when the bar is
  inactive. den's icon was a fixed colour that ignored all of that.
- **The shape carries the state.** A template has no colour to spend,
  so the glyph is an outline when everything is clean and filled when
  something is dirty or unpushed.
- **Colour is kept for CI failing**, which is the one state worth
  interrupting someone for.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
