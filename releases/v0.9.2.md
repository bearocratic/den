# v0.9.2

The menu bar app keeps itself up to date, and stays out of the Dock.

## New

- **den updates itself.** It asks at startup and every six hours, says
  nothing until there is something to install, and offers it as an
  item in the menu. The package is signed, so an installed den refuses
  one we did not build.
- **Quit is in the menu.** It was only in the tray's right-click menu,
  which meant right-clicking a glyph nobody is told to right-click.

## Fixed

- **No Dock icon.** The bundle has always declared itself an agent,
  but the activation policy was set to Regular at startup and that
  wins; den now says it in code, which also covers running it straight
  from cargo.
- **Two watched folders of the same name are told apart.** A folder
  was labelled with the last segment of its path, so `~/work/projects`
  and `~/personal/projects` both read "projects". A label now grows
  leftwards until it is unique, and only the ones that clash grow.

## Install

```sh
brew tap bearocratic/tap
brew install den
# or upgrade
brew upgrade den
```
