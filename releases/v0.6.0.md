# v0.6.0

_Sessions: Den now remembers what you cared about, separately for each set of folders you open._

## Highlights

- **Per-session persistence at `~/.den/`.** State lives under `~/.den/`. Pins, sort mode, show-hidden, and last filter are scoped to a session ID derived from the canonicalized base directories you launched with — so `den ~/work` and `den ~/personal` keep their own pins and preferences. Hidden stays global (`~/.den/hidden.txt`) so a vendor mirror you mute stays muted everywhere.
- **CLI subcommands.** `den ls` lists every saved session (`<id>  <bases>  (N pins)`), `den forget <id>` removes one, `den help` prints full help. The bare `den [paths]` invocation still launches the TUI.
- **Panic-resilient terminal.** Den now installs a panic hook that disables raw mode and leaves the alternate screen before the panic message prints — so an unexpected error can't strand your shell in a broken state.
- **Pinned tiles always lead the grid.** Pinned repos now occupy a dedicated **pinned** section at the top regardless of dirty/clean state. State color still appears on the tile itself, but the section header makes the bookmark intent unambiguous.
- **Migration on first launch.** If you have an existing `~/.config/den/{pins,hidden}.txt` from earlier versions, hidden moves to `~/.den/hidden.txt`, pins copy into the *current* session's pin file, and the legacy directory is removed. Migration is reported in the startup output.
- **Underlined CI run URL.** The `https://github.com/.../runs/123` shown next to a failing/running CI line now uses an underline + brighter foreground — reads as a real link.

## Install

```sh
brew tap bearocratic/tap
brew install den

```
